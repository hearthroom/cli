# hearthroom card visibility

Read or change who can access the linked card

## Commands

- [`hearthroom card visibility get`](/manual/card/visibility/get/) — Read visibility or check an unresolved operation
- [`hearthroom card visibility set`](/manual/card/visibility/set/) — Change visibility without submitting for review

## Global options

```
      --api string          provider API base (default from config or https://api.harperharbor.com)
      --config-dir string   config directory (default $HEARTHROOM_CONFIG_DIR or the user config dir)
      --json                machine-readable JSON output
      --site string         community site (default from config or https://sukisuki.ai)
```
